How are course grades calculated?

Letter grades are first converted to a 4.0 scale based on the following table.

Letter 4.0 Grade
A+ 4.0
A 4.0
A- 3.7
B+ 3.3
B 3.0
B- 2.7
C+ 2.3
C 2.0
C- 1.7
D+ 1.3
D 1.0
F 0.0

For each type of assessment, the grades of that assessment type are averaged. Then, the averages for each type of assessment are multiplied by their percentage of the grade and added.

How do assessment weights work?

Each type of assessment makes up a certain percentage of the grade. For example, tests may be worth 40% while quizzes, homework, and participation are worth 20%.
